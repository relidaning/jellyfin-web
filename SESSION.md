# Sessions

## 2026-07-07 — Fix subtitle-seeking `d` key bug + add audio-only playback
Fixed the subtitle-seeking feature's `d` key appearing to "get stuck" on rapid presses: `seekToSubtitleCue()` in `src/plugins/htmlVideoPlayer/plugin.js` set `mediaElement.currentTime` but never updated the cached `#currentTime` field that `currentTime()` prefers, so a second quick press recomputed from a stale pre-seek position (not a keymap conflict). Also added a "Play audio only" context-menu entry (for shadowing/language-learning use) that routes video items through the existing `Audio/{id}/universal` endpoint via a new `playAudioOnly` flag threaded through `playbackmanager.js`, `itemContextMenu.js`, and `remotecontrol.js`; verified live against a real Jellyfin server with Playwright (confirmed zero `Videos/...` requests, ffmpeg `-vn`, working resume position) and fixed two pre-existing bugs it exposed along the way (HLS `NullReferenceException` for non-audio-native sources, worked around with a dedicated progressive/mp3 stream URL; and an unguarded `item.MediaStreams[0].Type` crash in remotecontrol.js's Now Playing page, fixed with optional chaining). Accepted trade-off: no on-screen subtitles in audio-only mode.
